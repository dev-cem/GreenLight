# CLAUDE.md

Instructions for Claude Code when working in this repository.

## Verifying changes

- Do NOT run `flutter run` to test changes.
- Use `flutter analyze` for linting/verification instead.

## Permissions

- Do not ask for approval before running commands, except for very important/risky ones (e.g. destructive git operations, publishing, deleting files, force pushes). Proceed autonomously otherwise.
